# Figures

This directory contains the **polished figure files** as they will appear in the
paper.

## File naming convention

```
Figure_2_draft_YYYY-MM-DD.<ext>   ← near-complete draft, date-stamped
Figure_2_final.<ext>               ← final version (added when ready for submission)
```

## Formats

| Format | Use |
|---|---|
| `.pdf` | Print / journal submission |
| `.svg` | Editable vector (Illustrator source) |
| `@4x.png` | High-res raster (web, slides) |
| `@4x.jpg` | Compressed high-res (web) |
